# APCSFinalProject

The Last Two Brain Cells at 2 AM

Shyne Choi and Annabel Zhang	Period 3

A recreation of a familiar game: sudoku. The program will encompass a processing/java approach, keeping the basic features and rules, and aiming for a simple-to-use game. The main game will be on a 9 by 9 grid that provides helpful color coding to indicate various status. It will also include a sidebar on the right with the number options and a variety of tools. This includes a help button for an instructions manual as well as an erase tool to clear the selected square.
